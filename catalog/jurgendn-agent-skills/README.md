## Installation

**Caution:** No license grant was identified for the assessed repository snapshot. Establish the applicable rights before copying or installing. The separately fetched `skills` CLI is unassessed and this command does not pin the reviewed source. It selects all matching skills; review its selections and destination.

The pinned [README](https://github.com/jurgendn/agent-skills/blob/f290312fb6c55a044402e8649afff5c112e660ab/README.md#install) documents this shell command, requiring Node.js and `npx`:

```bash
npx skills add https://github.com/jurgendn/agent-skills.git --skill '*'
```

The README says this discovers skills nested by category and installs them under their bare names. User or project destination depends on installer settings and selections; no pinned single-item command was verified. The command and wrapper scripts were not run.
