## Installation

**Caution:** The pinned README installs the full plugin, including components outside these item assessments, from a moving marketplace. Review its contents and host permissions before use. The marketplace and installer versions are independent and unassessed.

The [upstream README](https://github.com/obra/superpowers/blob/8ca22dba9a94f28898bbce59f2537ff4d87c747d/README.md#installation) documents this command inside Claude Code:

```text
/plugin install superpowers@claude-plugins-official
```

It installs the plugin, not an individual pinned skill. Exact destination and scope depend on Claude Code and marketplace configuration. No item-specific pinned installation command was verified.
