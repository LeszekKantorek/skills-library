## Installation

**Caution:** The `skills` installer is separately fetched and unassessed. The command selects a moving repository, and the README says the CLI sends anonymous install telemetry by default. Check the installer, prompts and destination before use.

The [upstream README](https://github.com/adewale/anti-slop-writing/blob/53370ff70b6d1da376e053cf144d39dca8d64f9e/README.md#installation) documents this shell command, requiring Node.js and `npx`:

```bash
npx skills add adewale/anti-slop-writing
```

The README identifies the skill directory as the installable unit; actual user or project destination depends on the installer. No pinned install command was verified.
