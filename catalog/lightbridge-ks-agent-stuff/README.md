## Installation

**Caution:** This upstream command installs the full coding plugin, including components outside these item assessments, from a moving marketplace. The host, marketplace and plugin installer are unassessed; review selected components and permissions before use.

The [upstream README](https://github.com/Lightbridge-KS/agent-stuff/blob/e1fd32d0dbad3d495a4ec80966ff69b5bd1a9b3d/README.md#claude-code-plugin-marketplace-claude-code-only) gives these commands inside Claude Code:

```text
/plugin marketplace add Lightbridge-KS/agent-stuff
/plugin install coding@lightbridge-skills
```

These install the coding plugin rather than a single pinned item. The destination and scope depend on the host. No pinned single-item command was verified.

Installation commands were not run.
