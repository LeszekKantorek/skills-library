# ccheney/robust-skills

[ccheney/robust-skills](https://github.com/ccheney/robust-skills) provides agent skills. Reports cover only the named items and recorded versions, not the whole repository.

* [clean-ddd-hexagonal](clean-ddd-hexagonal.md)
* [modern-javascript](modern-javascript.md)

## Installation

**Caution:** The separately fetched `skills` CLI and its selections and destinations are unassessed; these commands select a moving repository rather than the assessed commit. Check installer and target paths before use.

The [upstream README](https://github.com/ccheney/robust-skills/blob/0eea7b060d12e3520556a73b15fbfa79480987d1/README.md) documents these shell commands, requiring Node.js and `npx`:

```bash
npx skills add https://github.com/ccheney/robust-skills --skill clean-ddd-hexagonal
npx skills add https://github.com/ccheney/robust-skills --skill modern-javascript
```

Each selects the named skill; actual user or project destination depends on the installer. No supported commit-pinned command was verified.

Installation commands were not run.
