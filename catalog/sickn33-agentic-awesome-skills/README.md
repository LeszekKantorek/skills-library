## Installation

**Caution:** The upstream command uses a separately fetched installer and does not select the reviewed commit. It can install many skills and write to a Codex skills directory. Review the installer, selected items and destination first.

The [upstream README](https://github.com/sickn33/agentic-awesome-skills/blob/4a293dda377bfb75a7e1f80e1ee3c8f3bd5b7527/README.md#installation) documents this shell command, requiring Node.js and `npx`:

```bash
npx agentic-awesome-skills --codex
```

The installer version, selection and exact destination are unassessed; the pinned setup guide identifies `.codex/skills/` as a Codex target. The README also documents a release-pinned dry-run for other example skills; that example does not establish installation of these pinned items.
