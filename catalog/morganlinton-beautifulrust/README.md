# morganlinton/BeautifulRust

The [repository](https://github.com/morganlinton/BeautifulRust) contains three Rust skills: [rust-best-practices](rust-best-practices.md), [rust-review](rust-review.md), and [rust-port](rust-port.md). The reports cover their skill instructions and shared guidance, not the repository's separate MCP server, lints, benchmarks or installation tooling.

## Installation

The pinned [README](https://github.com/morganlinton/BeautifulRust/blob/edd3e86087eda07983251056508fe3b8856d85d7/README.md#install) documents `npx skills add morganlinton/BeautifulRust` (Node 22.20 or later, project scope by default; `-g` selects user scope). It also documents `codex plugin marketplace add morganlinton/BeautifulRust` followed by `codex plugin add beautiful-rust@beautiful-rust` to install all three as a plugin. The source and installer are moving, independently versioned components; neither command pins the assessed commit. The installer, plugin host and actual installation behavior were not assessed or executed.
